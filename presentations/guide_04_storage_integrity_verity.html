Physical Threat

플래시 칩오프(Chip-off) 공격

"디바이스를 끄면 소프트웨어 규칙은 사라진다"

로봇의 eMMC 칩을 떼어내어 외장 리더기에 꽂으면,
읽기 전용(ro) 설정과 파일 권한은 오프라인에서 무용지물이 됨.

  • 공격자가 외부 PC에서 /bin/bash나 /etc/shadow를 직접 수정
  • 수정된 플래시 칩을 다시 붙이고 부팅하면 커널은 변조 사실을 모른 채 백도어 실행
Mathematical Structure

Merkle 트리 (해시 피라미드)

10GB 전체 디스크를 매번 스캔하지 않고,
단 32바이트 루트 해시(Root Hash) 하나로 전체 파티션을 검증하는 알고리즘!

4KB 블록 단위 해싱

데이터를 4096바이트 단위로 쪼개어 계층적으로 SHA-256 해시를 요약.

1바이트 변조 검출

단 1비트만 바뀌어도 피라미드 꼭대기의 루트 해시가 완전히 뒤바뀜!

Kernel Driver

Linux dm-verity 온더플라이 검증

App -> read(/bin/sh) -> dm-verity 커널 드라이버
                           |
                           +-> 디스크에서 4KB 블록 읽음
                           +-> Merkle 트리 경로 해시 실시간 계산
                           |
  [일치: 정상 4KB 페이지 메모리 전달]  [불일치: I/O Error(EIO) 즉시 반환!]
  [프로세스 정상 실행]               [프로세스 강제 종료, 변조 코드 차단]

부팅 시 디스크를 전수 스캔하지 않으므로 부팅 딜레이 0초!

Immutable Architecture

불변 파일시스템과 자가 복구 (Self-Healing)

EROFS + dm-verity + OverlayFS 3중 결합

Lower Layer (EROFS)

시스템 바이너리, 라이브러리 저장.
100% 불변 읽기 전용 & dm-verity 보호.

Upper Layer (tmpfs)

RAM 메모리 기반 쓰기 계층.
런타임 로그, 임시 파일 기록 허용.

💡 악성코드가 침투해도 재부팅(Power Cycle) 시 RAM이 증발하여 100% 원상 복구!

Key Takeaway

핵심 요약

  • 물리 공격 차단: 오프라인 칩오프 조작을 수학적 Merkle 해시로 탐지
  • 실시간 보호: dm-verity 드라이버가 4KB 블록마다 온더플라이 검증
  • 변조 즉각 격리: 변조 블록 읽기 시 커널이 EIO 에러 발생시켜 실행 차단
  • 불변 자가 복구: EROFS 불변성과 OverlayFS 메모리 레이어로 재부팅 시 자동 치유
