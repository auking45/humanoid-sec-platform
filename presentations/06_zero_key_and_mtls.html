SECURE WORLD COMMUNICATION

Zero Plaintext Key 정책 & Secure World TLS 1.3 mTLS

비추출성 암호 키 격리, RFC 7512 URI 파이프라인 및 안전한 관제 통신

SoftHSMv2 PKCS#11 • OP-TEE PKCS#11 TA • OpenSSL 3.x Provider • TLS 1.3 PFS

파일시스템 평문 개인키의 치명적 위험성

💥 평문 개인키 파일 노출 위협

  • 디스크에 .key 또는 .pem 저장 시 스토리지 덤프 1회로 키 유출.
  • 공격자가 기기 개인키를 탈취하여 가짜 로봇을 복제(Cloning).
  • 클라우드 관제망에 침투하여 허위 센서 데이터 및 원격 조작 수행.

🛡️ Zero Plaintext Key 원칙

  • 플랫폼 전체에서 평문 개인키 파일 저장을 엄격히 금지.
  • 키는 오직 HSM / Secure World 내부에서만 생성 및 봉인.
  • 외부에는 오직 RFC 7512 pkcs11: 식별자 URI만 노출.

암호 키 계층 구조 (Key Hierarchy - Archify)

Tier 1 오프라인 빌드/서명 키 • Tier 2 디바이스 런타임 TEE 격리 키 • Tier 3 공개 인증서

SoftHSMv2 오프라인 서명 파이프라인

평문 키 노출 없이 모든 보안 서명을 PKCS#11 토큰으로 수행:

  • CKA_EXTRACTABLE=FALSE:
    • 생성된 개인키는 하드웨어/토큰 외부로 절대 추출(Export) 불가능.
  • RFC 7512 pkcs11: URI 참조: 
    # 커널 모듈 서명 예시
sign_helper.sh kmod \
  --uri "pkcs11:token=HumanoidSecToken;object=KernelModuleSigningKey" \
  --in custom_driver.ko
  • FIPS 물리 HSM 무수정 전환:
    • 환경변수만 교체하여 YubiHSM, Thales 등 FIPS 140-3 Level 3 하드웨어로 즉시 전환.

Secure World mTLS 핸드셰이크 시퀀스 (Archify)

ClientHello → ServerHello → OP-TEE PKCS#11 TA C_Sign 서명 위임 → TLS 1.3 확립

OpenSSL 3.x Provider 연동 아키텍처

Normal World 애플리케이션이 TEE 내부 키로 mTLS 핸드셰이크를 수행하는 메커니즘:

  • OpenSSL 3.x pkcs11-provider:
    • 레거시 OpenSSL 엔진 대신 최신 Provider 프레임워크 탑재.
    • TLS 핸드셰이크 중 CertificateVerify 서명 요청 발생 시, OP-TEE PKCS#11 TA로 SMC 호출을 전달.
  • Secure SRAM 서명 실행:
    • ECDSA P-256 개인키 연산이 오직 TrustZone Secure SRAM 내부에서만 실행.
    • Normal World 메모리나 CPU 레지스터에 개인키가 단 1비트도 노출되지 않음.

TLS 1.3 상호 인증 및 완전 순방향 비밀성 (PFS)

상호 인증 (Mutual TLS)

  • 서버와 로봇 클라이언트가 서로 신뢰된 CA 인증서 체인을 엄격히 상호 검증.
  • 자체 서명된 위조 인증서 제시 시 핸드셰이크 즉각 단절 (ATK-05).

완전 순방향 비밀성 (PFS)

  • 세션마다 임시 Diffie-Hellman(ECDHE) 키 교환 수행.
  • 향후 장기 인증키가 갱신/폐기되더라도 과거 캡처된 통신 패킷 복독 불가 (ATK-10).

휴머노이드 보안 플랫폼 전체 종합 (Summary)

  • 하드웨어에서 클라우드까지 끊김 없는 신뢰 체인 (Chain of Trust):
    • BootROM / eFuse → TF-A → OP-TEE → UEFI db → Kernel KSPP → EROFS dm-verity → IMA fTPM → Secure mTLS.
  • 10대 공격 시나리오 100% 방어 실증 (Fail-Secure):
    • 물리 플래시 변조, 루트킷 주입, 메모리 스누핑, Quote 재전송, 키 유출 공격 완전 차단.
  • 실제 양산 하드웨어 1:1 호환:
    • NVIDIA JetPack 7.2.1 (L4T R39.2.1) 공식 규격을 준수하여 양산 보드 즉시 적용 가능.
