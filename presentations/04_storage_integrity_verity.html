IMMUTABLE STORAGE INTEGRITY

EROFS + dm-verity + OverlayFS 스토리지 파이프라인

오프라인 칩 분리(Chip-off) 변조 차단 및 4KB 블록 단위 무결성 보장

Linux dm-verity • SHA-256 Merkle Tree • EROFS (Enhanced Read-Only FS) • SoftHSM RSA-PSS 3072

오프라인 플래시 칩 분리 공격 (Chip-off Attack)

⚠️ 일반 ext4 스토리지의 취약점

  • 로봇 본체에서 eMMC/UFS 플래시를 탈거하여 프로그래머로 덤프.
  • 루트 파일시스템의 /usr/bin/robot_controller에 백도어 삽입.
  • 일반 파일시스템은 재조립 후 부팅 시 변조된 코드를 아무런 경고 없이 실행.

🛡️ dm-verity 블록 암호화 검증

  • 스토리지 전체를 읽기 전용(EROFS)으로 봉인.
  • 모든 4KB 데이터 블록을 머클 해시 트리(Merkle Tree)로 결합.
  • 단 1비트의 변조라도 읽는 순간 커널 I/O 에러(EIO)를 발생시켜 실행 차단.

스토리지 무결성 파이프라인 아키텍처 (Archify)

EROFS 이미지 생성 → SHA-256 Merkle 해시 트리 구축 → HSM Root Hash 서명 → dm-verity 마운트

EROFS (Enhanced Read-Only File System) 채택 이유

임베디드 로보틱스 및 고성능 AI 추론 시스템에 최적화된 파일시스템:

  • 고성능 블록 I/O: 고정 출력 압축 알고리즘(LZ4, LZMA)으로 읽기 지연(Latency) 최소화.
  • 원천적 불변성 (Immutability): 파일시스템 메타데이터 자체가 읽기 전용 구조로 설계되어 런타임 파일 덮어쓰기 불가.
  • dm-verity와의 완벽한 궁합: 4096바이트 고정 블록 구조로 dm-verity 머클 해시 트리 계산 효율 극대화.

dm-verity 머클 트리 및 Root Hash 서명

SoftHSMv2 오프라인 DmVeritySigningKey(RSA-PSS 3072) 서명 파이프라인:

  • Merkle Tree 구성:
    • Level 0: 데이터 블록(4KB) 각각의 SHA-256 해시.
    • Level 1 ~ Top: 상위 해시 노드를 결합하여 최종 단 1개의 64자리 Root Hash 산출.
  • PKCS#7 디지털 서명:
    • 산출된 Root Hash를 SoftHSMv2 토큰 내부에서 RSA-PSS 3072로 암호 서명 (verity.roothash.sig).
  • 위조 방어 (ATK-03B):
    • 공격자가 이미지를 변조하고 머클 트리를 재계산하더라도, HSM 서명을 위조할 수 없으므로 부팅 불가.

OverlayFS 런타임 결합 (쓰기 허용과 불변성 공존)

로봇 운영체제가 로그 기록, 네트워크 설정, 임시 파일을 다루는 방법:

  • lowerdir: /dev/mapper/root-verity (EROFS dm-verity 보호 읽기 전용 루트)
  • upperdir: tmpfs RAM 디스크 (/mnt/overlay/upper)
  • workdir: tmpfs 작업 디렉토리 (/mnt/overlay/work)
💡 런타임에 쓰여진 모든 변경사항은 휘발성 RAM(tmpfs)에만 기록되며, 재부팅 시 100% 무결한 초기 상태로 원상 복구.

실증 검증: ATK-03 오프라인 1바이트 변조 방어

🔴 Red Team 공격

  • rootfs.erofs 이미지의 1024번째 오프셋 데이터 1바이트 비트플립.
  • 변조된 이미지에 맞추어 Root Hash를 재계산한 후 서명 우회 시도.

🔵 Blue Team 방어

  • veritysetup verify 수행 시 즉각 해시 불일치 탐지 및 FAIL 에러 발생.
  • 위조된 Root Hash는 DmVeritySigningKey 공개키 서명 검증에서 100% 거절.

핵심 요약 (Key Takeaways)

  • 오프라인 덤프 공격 차단: 4KB 블록 단위의 실시간 SHA-256 검증으로 칩 레벨 변조 완전 방어.
  • 머클 루트 암호 서명: 오프라인 SoftHSM 키로 서명되어 공격자의 Merkle Tree 재생성 무력화.
  • 재부팅 복원력: OverlayFS와 tmpfs 결합으로 런타임 오염이 재부팅 후 영구 지속되지 않음.
